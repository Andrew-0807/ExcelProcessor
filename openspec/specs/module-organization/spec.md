## Requirements
### Requirement: Modular Directory Structure
The system SHALL use a modular directory structure where each feature is grouped with its dependencies and useless scripts are discarded.

#### Scenario: Code placement
- **WHEN** a new feature is added or an existing one is modified
- **THEN** it must be placed thoughtfully in a dedicated module folder, ensuring the overall codebase remains efficient and organized
